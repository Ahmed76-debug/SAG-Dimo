# ☕ كافيه برو — نظام إدارة كافيه متكامل

نظام ويب عربي (RTL) لإدارة الكافيه: نقطة بيع، طاولات وطلبيات، مخزون ووصفات،
مشتريات، حسابات وقيود يومية، شيفتات، فروع، صلاحيات لكل مستخدم، وتقارير مالية
كاملة — مع واجهة عصرية (فاتح/داكن) تعمل على الكمبيوتر والموبايل.

---

## ⚡ التشغيل السريع (Windows)

1. اضغط مرتين على `start.bat`
2. المتصفح هيفتح لوحده على: <http://localhost:3000>
3. سجّل الدخول:

```
اسم المستخدم: admin
كلمة المرور: 1234
```

> أول تشغيل فقط: `start.bat` هيثبّت الحزم (`npm install`) لوحده لو مش موجودة.

### تشغيل يدوي

```bash
cd C:\Users\CONNECT\Desktop\OPEN\cafe-manager
npm install
npm start
```

## 🗄️ قاعدة البيانات

النظام بيدعم قاعدتين، ويختار تلقائياً:

| الحالة | القاعدة | التخزين |
|---|---|---|
| مفيش `DATABASE_URL` | **SQLite** (عبر `node:sqlite`) | ملف `cafe.db` جوه المشروع |
| فيه `DATABASE_URL` | **MySQL / MariaDB** | قاعدة البيانات على الاستضافة (دائمة) |

### MySQL / MariaDB (للنشر)

```bash
set DATABASE_URL=mysql://USER:PASSWORD@HOST:3306/DBNAME
npm start
```

- الجداول والبيانات الافتراضية بتتعمل تلقائياً أول تشغيل.
- كل الاستعلامات مكتوبة بشكل يشتغل على القاعدتين.
- PostgreSQL مش مدعوم في النسخة الحالية.
- دليل النشر الكامل + نقل بيانات SQLite إلى MySQL: [`DEPLOY-MYSQL.md`](DEPLOY-MYSQL.md).

## ✨ المميزات

- **لوحة تحكم**: مبيعات، فواتير، مشتريات، صافي الدخل + رسم بياني لآخر 7 أيام.
- **شاشة بيع (POS)**: بحث، باركود، سلة، دفع نقدي/كارت/محفظة، طباعة فاتورة.
- **الطاولات والطلبيات**: فتح طاولة، إضافة أصناف، دفع جزئي/كامل، نقل طاولة، إغلاق وتحويل لفاتورة.
- **الأصناف والوصفات**: مكونات، تكلفة، سعر بيع، باركود، حساب تكلفة الوصفة.
- **المشتريات والموردين**: تسجيل شراء + قيد يومية تلقائي.
- **المالية**: إيرادات ومصروفات + قيود تلقائية.
- **المحاسبة**: دليل حسابات، قيد يدوي متوازن، دفتر يومية.
- **الشيفتات**: فتح/إغلاق، تقرير شيفت (نقدي متوقع، وسائل دفع).
- **التقارير**: قائمة الدخل، الميزانية، حقوق الملكية، المخزون، وسائل الدفع، تصدير CSV، طباعة.
- **الفروع**: تعدد الفروع + عزل بيانات كل فرع تلقائياً.
- **المستخدمين والصلاحيات**: صلاحية عرض/إضافة/تعديل/حذف لكل صفحة — **مفروضة على السيرفر** مش الواجهة بس.
- **أمان الجلسات**: توكن جلسة (12 ساعة) + تسجيل دخول تلقائي.
- **النسخ الاحتياطي**: تنزيل/استرجاع كل البيانات كملف JSON.
- **ثيم فاتح/داكن** + تصميم متجاوب للموبايل.

## 🔐 الصلاحيات

كل مستخدم ليه مصفوفة صلاحيات:

```json
{
  "sales":    { "v": 1, "a": 1, "e": 1, "d": 1 },
  "purchases":{ "v": 1, "a": 1 }
}
```

- `v` عرض — `a` إضافة — `e` تعديل — `d` حذف
- دور **مدير** بيتخطى كل الصلاحيات.
- الكاشير بيشوف بيانات فرعه فقط (حتى لو حاول يبعت طلب بفرع تاني).
- النسخ الاحتياطي/الاسترجاع وإدارة الفروع للمدير فقط.

## 🚀 النشر

### alwaysdata (موصى به — Node + MySQL مجاناً)
1. أنشئ قاعدة MySQL من لوحة alwaysdata (ترميز `utf8mb4`).
2. ارفع ملفات المشروع **بدون** `node_modules` و`cafe.db*` و`.env`.
3. على الخادم: `npm install --omit=dev`.
4. أنشئ `.env`:
   ```
   DATABASE_URL=mysql://USER:PASSWORD@HOST:3306/DBNAME
   ```
5. أمر التشغيل: `npm start` أو `node server.js`.
6. افتح الرابط وسجّل دخول بـ admin / admin123 وغيّر كلمة السر فوراً.

### Render / Koyeb / Glitch (Node)
- يدعمون Node لكن **لا يوفرون MySQL**؛ استخدم MySQL خارجية (مثل alwaysdata أو db4free.net).
- على الخطة المجانية قد ينام التطبيق أو تُفقد الملفات المحلية — MySQL الخارجية أفضل.

### ⚠️ InfinityFree
- بتوفر **PHP + MySQL** فقط، **بدون Node.js** — يعني المشروع ده **مش هيشتغل عليها**.
- البدائل المجانية اللي تدعم Node: alwaysdata، Render، Koyeb، Glitch، Oracle Cloud Always Free.

## 🛠️ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `EADDRINUSE` — البورت مشغول | `taskkill /f /im node.exe` ثم شغّل تاني، أو غيّر البورت: `set PORT=3001` |
| قاعدة البيانات مش بتفتح | امسح `cafe.db` (هيتعمل جديد بالبيانات الافتراضية) |
| نسيت كلمة السر | على MySQL: نفّذ [`RESET-ADMIN-MYSQL.sql`](RESET-ADMIN-MYSQL.sql) من phpMyAdmin (يعيدها إلى `admin123`). محلياً: امسح `cafe.db` (ويرجع admin/admin123) أو عدّل الجدول. |
| MySQL مش بيتصل | تأكد من `DATABASE_URL` بصيغة `mysql://...`، ومن أن المستخدم لديه صلاحية الاتصال من IP الخادم. |
| `PostgreSQL غير مدعوم` | هذا الإصدار يستخدم MySQL أو SQLite فقط؛ غيّر الرابط إلى `mysql://...`. |
| انتهت التجربة / ظهرت شاشة التفعيل | استورد ترخيص `.caplic` أو فعّل بمفتاح `CAFE-...` من المورد؛ بيانات قاعدة البيانات تبقى محفوظة |
| `الترخيص غير مرتبط بهذا الجهاز` | أصدر ترخيصًا جديدًا برمز الجهاز الحالي، أو أعد ربط الترخيص الأونلاين |

# Baraka Market (نظام ويب — المصدر)

نظام ويب متكامل لإدارة السوبرماركت/نقطة البيع والمخزون والمحاسبة (واجهة متصفح + خادم Node محلي) مع قاعدة بيانات SQLite.

## التشغيل كنظام ويب
- المتطلبات: **Node.js >= 22.5**
- التشغيل:
  - `npm start` أو `npm run dev`
- الرابط: `http://localhost:4300` (افتراضيًا على `localhost`)
- قاعدة البيانات (محفوظة): `data/baraka.db` (SQLite)

## بيانات الدخول والبيانات التجريبية
- الدخول الافتراضي: `admin / admin123`
- يتضمن بذرًا أوليًا غنيًا (فروع، مستخدمون، أصناف/تصنيفات ومخزون، عملاء وموردون، وردية، ومجموعة عمليات مبيعات/مشتريات/مصروفات/حركات) لعرض شكل الصفحات بشكل مكتمل عند أول تهيئة.

## ملاحظات
- نظام ويب بدون تبعيات خارجية وقت التشغيل.
- النسخ الاحتياطي: `npm run backup`.

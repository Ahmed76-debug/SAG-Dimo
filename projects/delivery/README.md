# Talabatak / Delivery (نظام ويب — المصدر)

منصة ويب لإدارة عمليات التوصيل والطلبات (كتالوج، طلبات، عملاء/طيارين/موردين، مخزون، عروض، محاسبة) بواجهة متصفح وخادم Node.

## التشغيل كنظام ويب
- المتطلبات: **Node.js >= 18**
- التثبيت والتشغيل:
  - `npm install`
  - `npm start`
- الرابط: `http://localhost:8080`
- قاعدة البيانات (محفوظة): `data/app.db` (SQLite افتراضيًا) أو MySQL عبر المتغير `DATABASE_URL`.

## بيانات الدخول والبيانات التجريبية
- الدخول الافتراضي: `admin / admin123`
- يتضمن بذرًا تجريبيًا غنيًا (بيانات مرجعية وتشغيلية ومحاسبية) لعرض شكل الصفحات عند التهيئة الأولى.

## النسخ الاحتياطي والـ ERP
- **مركز النسخ الاحتياطي** من القائمة: `#/backup` — إنشاء نسخة، تنزيلها، استعادتها، أو استعادة ملف `.db` / `.json` من الجهاز مع نسخة أمان تلقائية قبل الاستعادة.
- **مركز ERP للتوصيل** من القائمة: `#/erp` — مؤشرات الإيراد والتوصيل والتكلفة والربح والسيولة والمخزون، مع تسويات الطيارين وأداء الفروع ووسائل الدفع.
- شاشات المحاسبة التفصيلية متاحة أيضًا: دليل الحسابات واليومية، الخزائن والبنوك، أذون القبض والصرف، والتقارير المالية.

## أدوات مساعدة
- توليد مخطط قاعدة البيانات: `npm run db:schema`
- اختبار دخان: `npm run test:smoke`

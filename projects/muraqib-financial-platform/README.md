# منصة المراقب المالي المعتمد | Muraqib Certified Financial Controller

نظام ويب متكامل لأعمال المراقب المالي المعتمد: إدارة محفظة الشركات، ميزان المراجعة، القوائم المالية، المراجعة والاعتماد، التحليل المالي، الموازنة التقديرية، الأرشيف، التذكيرات، النسخ الاحتياطي، وصلاحيات الفريق — بواجهة عربية/إنجليزية كاملة.

## البنية الحالية

| الطبقة | التقنية |
| --- | --- |
| الواجهة | React 19 + TypeScript + Vite + Tailwind |
| الخادم | Node.js + Express 5 |
| قاعدة البيانات | SQLite عبر `node:sqlite` (`DatabaseSync`) |
| المصادقة | HMAC Token (صلاحية 7 أيام) |
| ملف البيانات | `data/muraqib.db` |

كل الجداول تُقرأ وتُكتب عبر REST API (`/api/tables/:table`)، ولا تعتمد الواجهة على IndexedDB لتخزين بيانات المنصة.

## التشغيل السريع

من جذر المشروع:

```bat
start-web.bat
```

أو من داخل مجلد المشروع:

```bat
start-web.bat
```

يفتح الخادم تلقائيًا على:

```
http://127.0.0.1:5183
```

مع فتح المتصفح الافتراضي مباشرة.

### التشغيل اليدوي

```bash
npm install

# تطوير: API على 5183 + Vite على 5173
npm run dev

# إنتاج: بناء الواجهة ثم تشغيل الخادم على 5183
npm run build
npm run server
```

## المميزات الرئيسية

- **بورتفوليو احترافي** يليق بمراقب مالي معتمد خبير.
- **دعم عربي / إنجليزي** مع RTL/LTR تلقائيًا.
- **عملات متعددة** + أسعار صرف محلية.
- **دليل حسابات ثنائي اللغة هرمي وعلمي**.
- **نظام CRUD كامل** في الإعدادات والمدخلات.
- **وضع داكن / فاتح**.
- **سير عمل إدخال خارجي + مراجعة واعتماد**.
- **توليد تلقائي**: قائمة الدخل، الميزانية العمومية، قائمة التغير في حقوق الملكية، قائمة التدفقات النقدية، قائمة المركز المالي، ميزان المراجعة.
- **تحليل مالي لكل قائمة على حدة**.
- **الموازنة التقديرية**.
- **أرشفة متقدمة + بحث**.
- **تذكير بالمواعيد**.
- **نسخ احتياطي / استعادة** (JSON كامل) + قابلية اختيار المسار.
- **تصدير PDF / Excel / طباعة مباشرة** (أزرار منفصلة).
- **صلاحيات وأدوار**.

## البيانات التجريبية

عند أول تشغيل يضيف الخادم:

- 3 شركات (تجارية، صناعية، خدمية).
- دليل حسابات أساسي (12 حسابًا).
- ميزان مراجعة معتمد بخطوطه.
- تذكير مراجعة.
- 5 مستخدمين تجريبيين.

لإعادة ضبط البيانات: أوقف الخادم، احذف `data/muraqib.db*`، ثم شغّله من جديد.

## واجهات API الرئيسية

| المسار | الوصف |
| --- | --- |
| `POST /api/auth/login` | تسجيل الدخول وإصدار Token |
| `GET /api/auth/me` | بيانات المستخدم الحالي |
| `POST /api/auth/logout` | إنهاء الجلسة |
| `GET /api/tables/:table` | جلب صفوف جدول |
| `POST /api/tables/:table` | إضافة صف |
| `PUT /api/tables/:table/:id` | تحديث صف كامل |
| `PATCH /api/tables/:table/:id` | تحديث جزئي |
| `DELETE /api/tables/:table/:id` | حذف صف |
| `POST /api/tables/:table/bulk-delete` | حذف مجموعة صفوف |

## النسخ الاحتياطي

- من داخل التطبيق: النسخ الاحتياطي والاستعادة (JSON) أو تصدير SQL.
- على مستوى الخادم: انسخ `data/muraqib.db` (مع `-wal` و`-shm` إن وجدت) بعد إيقاف الخادم.

# تسوق | Tasawuq Classifieds

موقع مبوبات احترافي لبيع وشراء السيارات والمنازل والأراضي مع نظام عمولة، صلاحيات المستخدمين، دعم الوضع الليلي/النهاري، ونظام نسخ احتياطي.

## المميزات

- 🏠 **ثلاثة أقسام رئيسية**: سيارات، عقارات، أراضي
- 📝 **CRUD كامل** لإدارة الإعلانات
- 👥 **نظام مستخدمين وصلاحيات** (مدير عام - مشرف - مستخدم)
- ✅ **مراجعة الإعلانات** قبل النشر
- 💰 **نظام العمولة** بين البائع والمشتري (قابل للتعديل)
- 🔍 **بحث وفلاتر متقدمة** حسب القسم، المدينة، السعر
- ❤️ **المفضلة** والرسائل
- 🌙 **Dark Mode / Light Mode**
- 📱 **تصميم متجاوب 100%** لجميع الأجهزة
- 🎨 **تصميم عصري مع Animations**
- 💾 **نظام نسخ احتياطي** لقاعدة البيانات
- 🖼️ **رفع صور وفيديوهات**
- 📊 **إحصائيات ولوحة تحكم شاملة**

## التشغيل المحلي

```bash
cd "Tasawuq"
npm install  # أو skip إذا node_modules موجود
node server.js
```

سيتم فتح الموقع على:
- الرئيسية: http://localhost:8080
- لوحة التحكم: http://localhost:8080/admin.html

## البيانات (Seed)

- عند أول تشغيل (DB فارغة) يتم إنشاء: 3 أقسام، 6 مستخدمين (مدير + مشرف + 4 مستخدمين)، 17 إعلان (16 منشور + 1 pending)، 2 معاملة، 5 رسائل، 6 مفضلة.
- إعادة تشغيل الخادم لا يعيد البذر (فقط إذا كانت DB فارغة).
- إعادة البذر (مفيد للاختبار): أوقف الخادم، احذف `data/tasawuq.db*`، ثم أعد التشغيل.
- الصور من Unsplash (fallback إلى `assets/placeholder.svg` عند عدم الاتصال).
- التحميل: `/uploads/` لملفات المستخدم (صور/فيديوهات).

## البنية

```
تسوق/
├── server.js        # خادم Node.js
├── lib/
│   ├── db.js       # قاعدة البيانات + Schema
│   ├── auth.js     # المصادقة والصلاحيات
│   └── upload.js   # رفع الملفات
├── public/         # الواجهة الأمامية
│   ├── css/        # التنسيقات
│   ├── js/         # JavaScript
│   └── uploads/    # الملفات المرفوعة
├── scripts/
│   └── backup.js   # نظام النسخ الاحتياطي
└── backups/        # مجلد النسخ الاحتياطية
```

## تقنيات المستخدمة

- **Backend:** Node.js (Vanilla) - بدون إطار عمل
- **Database:** SQLite (node:sqlite) للتطوير / MySQL للإستضافة
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Icons:** Bootstrap Icons
- **Fonts:** Cairo (Google Fonts)

## قاعدة البيانات

يستخدم المشروع `node:sqlite` المدمج مع Node.js 22+. قاعدة البيانات تُنشأ تلقائياً في `data/tasawuq.db` مع بيانات أولية.

## النسخ الاحتياطي

من لوحة التحكم > النسخ الاحتياطي، أو عبر الأمر:

```bash
node scripts/backup.js
```

سيتم حفظ النسخة في مجلد `backups/`

# Auto Car (نظام ويب — المصدر)

تطبيق ويب لإدارة معرض السيارات والمحاسبة (واجهة متصفح + خادم Node محلي) مع قاعدة بيانات SQLite محلية.

## التشغيل كنظام ويب
- المتطلبات: **Node.js >= 22.5**
- التشغيل:
  - `npm install` (لا توجد تبعيات خارجية مطلوبة)
  - `npm start` أو `npm run dev`
- الرابط: `http://localhost:4500`
- قاعدة البيانات (محفوظة): `data/autocar.db` (SQLite عبر `node:sqlite`)

## بيانات الدخول والبيانات التجريبية
- الدخول الافتراضي: `admin / admin123`
- عند أول تهيئة يتم بذر الإعدادات/العملات/المستخدمين/دليل الحسابات والخزائن والسنة المالية والبيانات المرجعية للسيارات، بالإضافة إلى **بيانات تجريبية** (عملاء، موردون، مركبات بحالات مختلفة، عمليات شراء/بيع مبسطة، مصروفات وسندات) لعرض شكل الصفحات — تُضاف مرة واحدة عند خلو بيانات التشغيل.

## ملاحظات
- هذا المجلد هو **مصدر نظام الويب**؛ لا يتم تعديل مجلدي نسخ سطح المكتب ضمن هذا السياق.
- النسخ الاحتياطي متاح عبر سكربت `npm run backup` وواجهات النظام.
